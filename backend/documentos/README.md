# Carpeta de documentos

Coloca aquí los archivos que quieres analizar:

- `.pdf` con texto real (los escaneados requieren OCR previo)
- `.txt` (por ejemplo, el texto copiado de Google Scholar)

La ingesta es automática: copia el archivo y ejecuta el pipeline
(`python main.py --todo` o la opción 2 del menú). No hay que registrar
nada más.

Los nombres largos se acortan automáticamente en los gráficos y en los
informes LaTeX.
